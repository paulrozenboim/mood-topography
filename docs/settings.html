What the wall is showing

The wall cycles its own views — the whole map, the last dozen journeys, the heaviest links, and one mood category at a time. It holds the full map for the whole of a cast, so a new path is always seen arriving among the others. Pausing the bulletin from the projection's own menu holds the view too.

Theme

One theme now applies to every operator page — Cast Path, Projection, Settings, and Archive stay in sync. Dark blends light additively (routes brighten where they overlap); Light blends like ink (better for a bright room).

Demo paths

Hidden everywhere by default — the wall, the terrain, the archive and the public results page all ignore them. Turn them on while there is nothing real to show yet, then turn them off before anyone arrives. They are still stored either way; this only controls whether they are drawn.

Public results page

Every receipt prints a QR to this page plus a path code, so participants land here during or after the night. It reads the live cloud log on its own — but that log keeps changing and can be cleared. Freeze results downloads results.json; drop that file into docs/ and push, and the page serves that fixed set forever.

The printed QR always points at PUBLIC_BASE in assets/core.js, never at whatever address this kiosk is on — check it before a print run.
